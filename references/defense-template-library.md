# 开题答辩模板库

本库包含五套由用户提供的学术汇报及开题答辩文件提取的模板，共 67 张可复制版式。原有华工蓝通用模板仍为 `assets/scut-blue-template.pptx`。

## 选择与定位

路径均相对于技能根目录。先看 [模板总览](../assets/defense-templates/模板总览.jpg) 或 [逐页索引](../assets/defense-templates/版式索引.html)。精确文件位置、页面用途、页数与文件校验值在 [模板目录](defense-template-catalog.json)。

| 标识 | 模板 | 页数 | 主要特点 |
|---|---|---:|---|
| `template-1` | 模板一 | 13 | 华工蓝、校徽水印、横向章节带，适合需要多栏说明和目标分层的报告。 |
| `template-2` | 模板二 | 15 | 曲线五项导航、深蓝页眉，含原生流程与阶段推进布局。 |
| `template-3` | 模板三 | 16 | 青蓝导航、递进圆环与桥梁背景，适合研究方案、方法与阶段工作展示。 |
| `template-4` | 模板四 | 15 | 深蓝学位帽与灰蓝章节页，含四象限比较、平衡示意及章节安排。 |
| `template-5` | 模板五 | 8 | 天空页眉与深蓝横幅，含案例多图、时间轴、三栏图文与四图说明。[解析说明](template-five-profile.md) |

## 使用方式

- 用户指定模板编号时，按目录选择对应 PPTX。用户提到“这些开题模板”时，从此库按内容关系选择；一般论文汇报沿用原有默认模板。用户未指定时，可先选与材料最匹配的一套，并简要说明。
- 选定一套后，在本次工作目录中复制源模板，按报告内容复制、删选和重排页面。跨套借用时统一整稿配色、字体、导航和章节样式。最终页数由实际内容决定。
- `page` 是提取后 PPTX 内从 1 开始的实际页码；`source_page` 仅用于追溯原稿。编写计划时使用 `page`，不要把原稿页码填入 `templateSlide`。
- 模板内的通用文字用于说明该版式可承载的内容。正式汇报须逐框替换，同时核对封面、目录、章节编号、页眉导航、页码和结束页。
- 浅色“插入……”区域是原生提示形状。加入所需研究图后删除提示形状；原稿研究截图已提供换图位置。母版校徽、校园照片与装饰图保留原有形式。
- 正文文字、原生表格与流程节点保持可编辑。页眉导航通常继承自版式，需要同步修改对应版式。组合形状可在组内编辑。修改表格时逐单元格处理；按页内唯一形状 ID 或明确的组合路径定位复杂对象。
- 五套模板使用当前演示文稿/PPTX 编辑工具直接编辑副本。确定页面时，按 `ppt/presentation.xml` 的 `sldIdLst` 与关系文件解析实际部件；放映第 N 页不一定对应 `slideN.xml`。各套部分页面含重名形状，复杂对象按页内唯一 ID 或组合路径定位。
- 本技能的 `render_template.mjs`、`preserve_template.py`、`prepare_template.py` 和 `finalize_scut.mjs` 保留为原有华工蓝专用流程。它们对页部件编号、文字名称、字体或画布有专用假设，五套模板库默认使用上述副本编辑流程。若后续扩展脚本，须先验证关系映射、重名对象、原生表格、图片、字体与画布均正确。
- 校验使用所选模板的实际尺寸和字体。模板一至三及模板五为 12192000×6858000 EMU，模板四为 9144000×5143500 EMU，均为 16:9。保留各自的字体、字号、内边距和行距，再按内容适配。
- 开题材料的出处按真实输入记录；文献出处、DOI 和逐页讲稿仅按实际任务要求填写。不要为了满足论文生成器的字段检查而编造参考文献或来源。
- 新报告完成后再检查每页的章节所属、目录对应关系与连续页码。逐页 WPS 预览；模板自身通过检查不能代替正式内容的溢出和遮挡检查。

## 开题报告材料

根据用户的开题报告、研究计划、论文或说明编排内容。区分已有研究基础、拟采用的方法、计划获取的数据与预期结果。没有实际结果时，按研究计划表达。出处与讲稿要求随本次交付目标确定。
