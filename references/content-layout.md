# 内容与布局

逐页计划先写清“听众要看懂什么”，再选择图形。记录本页论点、关键证据、阅读任务、信息关系、布局、来源和讲稿。以下是选择线索，按实际材料调整。

| 信息关系 | 适合的表达 | 保留的内容 |
|---|---|---|
| 比较方法或方案 | 同维度表格、并列对照 | 比较维度、适用条件、差异、选择依据 |
| 描述研究过程 | 顺序流程、阶段路线、泳道 | 步骤、输入输出、角色分工、反馈关系 |
| 依据条件选择路径 | 决策分支、双情境合流 | 判断条件、每条路径的依据及结果 |
| 汇聚不同研究传统 | 主题关系图、概念汇聚图 | 学科或观点差异、分析方式、共同主题和产出 |
| 说明筛选和纳排 | 筛选流程、带排除支路的漏斗 | 各阶段、标准、排除理由、复核与记录 |
| 提取与编码证据 | 字段表、证据矩阵、带注释的示例 | 字段含义、材料类别、分析用途、编码规则 |
| 解释结果与贡献 | 证据—发现—解释链、图表配结论 | 真实结果、证据联系、适用情境、不确定性 |
| 说明限制与偏差 | 限制—影响—处理对照 | 限制依据、可能遗漏的证据、判断边界 |
| 写作与质量评价 | 报告结构图、检查清单 | 应报告的信息、可检查依据、质量标准 |
| 提出背景、贡献或收束 | 原模板特色图文、主论点配关键依据 | 论文定位、核心判断、必要的解释与视觉识别 |

## 让图形承担解释

连线表示有依据的先后、因果、依赖或汇聚；表格围绕可比较维度组织；分支写明判断条件；清单给出具体可检查的内容。正文段落先拆出论点与证据，再放入相应结构。图形中的数值、时间、样本数量和关联必须有原文依据；示意结构应清楚标注其性质。

原模板配图与特色裁切可用于开场、转场、贡献或结尾，也可按内容需要组合进正文。根据图片在本页的实际作用确定面积，让核心证据和分析有足够空间。新建表格、流程、形状和连接线采用原生可编辑对象，并沿用华工蓝的色彩和字体层级。

## 保留内容深度

每页呈现一个清楚的主要判断及足以支持它的细节。方法页交代适用条件和关键操作，结果页提供证据及解释，评价页说明依据与边界。长内容可按论证层次拆页；讲稿补充背景、推导和现场衔接。保留来源定位，区分作者结论、原文案例和汇报者评议。

## 逐页与整稿检查

逐页确认第一眼可识别主论点，阅读顺序明确，文字层级和密度适合投影，关系线与表格语义正确，图文有足够间距，出处与讲稿齐全。

整稿用总览检查连续页面：它们分别要求听众比较、追踪步骤、判断条件、检查证据，还是理解结论？相同信息关系可以保持一致；当信息关系发生变化时，布局应随之调整。核对页面的信息重心、主视觉、密度和节奏，确保构图变化服务于理解。内容完整性与可读性共同决定最终页数。

## 合并独立正文（可选）

底稿与设计稿页数、页序相同，设计稿中的替换页保持可编辑。把需替换的 1-based 页码写成 JSON 数组，再运行：

```text
assemble_layout.py --base BASE.pptx --designed DESIGNED.pptx --pages PAGES.json --output CANDIDATE.pptx
```

此工具复制选定页及其关联的母版、版式、媒体和备注，并保留底稿其余页面。输出必须是新文件；合并后仍要校验并在 WPS 逐页检查。

## 章节与页码导航

有章节的汇报先列出章节序号、标题和页面范围。章节引导页与正文导航引用同一章节表，章节序号连续；页码按实际放映顺序单独计算，并明确标为页码。目录若存在，其章名、顺序与页面范围也应对应一致。交付前逐页核对章序、章节归属和页码，确认显示清楚、位置一致。
